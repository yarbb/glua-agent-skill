# GLua Agent Skill

[English](README.md) | [Русский](README.ru.md)

A skill for AI agents that write and maintain Lua code for Garry's Mod.

We actively use it while developing TOT-city. New code follows the Code Style in [`SKILL.md`](SKILL.md); focused edits preserve the conventions of the existing project.

## Use

- **Codex:** place this repository in `%USERPROFILE%\.codex\skills\glua-agent-skill\`.
- **Claude Code:** place it in `~/.claude/skills/glua-agent-skill/`, or in `.claude/skills/glua-agent-skill/` inside a project. See the [Claude Code skills documentation](https://code.claude.com/docs/en/skills).
- **Other agents and models, including DeepSeek and Gemini:** follow the instructions in your agent's documentation.
