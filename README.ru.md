# GLua Agent Skill

[English](README.md) | [Русский](README.ru.md)

Скилл для ИИ-агентов, которые пишут и поддерживают Lua-код для Garry's Mod.

Активно использую в своих проектах. Новый код следует Code Style из [`SKILL.md`](SKILL.md), а точечные правки сохраняют соглашения существующего проекта.

## Использование

- **Codex:** поместите репозиторий в `%USERPROFILE%\.codex\skills\glua-agent-skill\`.
- **Claude Code:** поместите его в `~/.claude/skills/glua-agent-skill/` или в `.claude/skills/glua-agent-skill/` внутри проекта. Подробности есть в [документации Claude Code по скиллам](https://code.claude.com/docs/en/skills).
- **Другие агенты и модели, включая DeepSeek и Gemini:** следуйте инструкции в документации вашего агента.
